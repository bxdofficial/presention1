# NPN Transistor Circuit Interactive Presentation

An interactive, animated educational presentation that demonstrates the complete operation of an NPN bipolar junction transistor (BJT) switching circuit.

## 🎯 Features

- **Interactive Intro & Outro Screens** - Engaging on/off switch animations
- **15 Educational Slides** - Comprehensive circuit analysis from basics to advanced concepts
- **Real-time Circuit Animation** - Visualize current flow and component states
- **Responsive Design** - Works on desktop and mobile devices
- **Keyboard Navigation** - Full keyboard support for accessibility
- **Auto-play Mode** - Optional automatic slide progression

## 🚀 Getting Started

### Prerequisites

- Node.js 18+ 
- pnpm (recommended) or npm

### Installation

```bash
# Install dependencies
pnpm install

# Run development server
pnpm dev

# Build for production
pnpm build

# Start production server
pnpm start
```

## 🎓 Educational Content

The presentation covers:

1. **Circuit Overview** - Introduction to NPN transistor switches
2. **Battery** - Power supply fundamentals
3. **Power Distribution** - Circuit wiring and voltage rails
4. **Collector Resistor (Rc)** - Current limiting principles
5. **LED Indicator** - Visual output demonstration
6. **NPN Transistor** - Three-terminal device operation
7. **Base Resistor (Rb)** - Input current control
8. **Input Signal** - Control voltage concepts
9. **Ground Connection** - Circuit return paths
10. **Cutoff State** - Transistor OFF mode
11. **Saturation State** - Transistor ON mode
12. **Current Amplification** - Beta factor explanation
13. **Transition Analysis** - Switching behavior
14. **Timing Parameters** - Speed characteristics
15. **Circuit Summary** - Complete review

## ⌨️ Keyboard Shortcuts

- `←` / `→` - Navigate between slides
- `Space` - Play/Pause presentation
- `Home` - Jump to first slide
- `End` - Show outro screen
- `Esc` - Pause playback
